## App Privacy

Data Not Collected. The apps send data only to the server the person enters,
which the household runs; nothing reaches Legitimate Enterprises or any third
party, and the apps have no analytics, advertising or crash reporting of their
own. This matches the published privacy policy.

## Age rating

The apps ship with no content. Answers that are facts: no advertising, no
in-app purchases, no chat or messaging, no user-generated content shared
between strangers, no unrestricted web access, no gambling; parental controls
yes. The content questions are a judgment, because a household's library can
hold anything: answer them for the kind of films the app exists to play, not
for the demo library alone.

## Review notes

```
Rabbit Ears is the player for a self-hosted media server. The app contains no media and no service of its own; it signs in to a server that a household runs on its own Mac. The publisher runs no server for customers.

For review we run a demo server that holds only Creative Commons films and music:

Server address: https://rabbit-ears-demo.legitimate.enterprises
Email: <reviewer account email>
Password: <reviewer account password>

On first launch, enter the server address, then the email and password. On Apple TV, choose "Enter an address"; the demo server is not on your network, so it will not appear in the list of servers found.

The app asks for local network access only to find a server on the same network. The demo server is reached over the internet, so the prompt can be declined.

Account deletion: on iPhone and Mac, open your profile and choose "Delete account". The Apple TV app only signs in to an existing account and cannot create one.

CarPlay (iPhone): the app uses the CarPlay audio entitlement to browse and play the music library.
```
